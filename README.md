# Encrypt Decrypt (Caesar Cipher)

A terminal-based text encryption and decryption program built in Python, using the Caesar Cipher technique.

## Features
- Encrypt a message by shifting each letter forward by a chosen number
- Decrypt a message by shifting each letter backward by the same number
- Preserves letter casing (uppercase/lowercase)
- Leaves non-alphabetic characters (numbers, symbols, spaces) unchanged
- Simple, interactive terminal interface

## How to Run
1. Make sure Python is installed on your system.
2. Run the program:
3. Choose an option: `1` to encrypt, `2` to decrypt, or `3` to exit.
4. Enter your message and a shift number.
5. View the encrypted or decrypted result.

## How It Works
The program uses a Caesar Cipher, shifting each letter of the alphabet by a fixed number of positions. For example, with a shift of 3, "a" becomes "d". Decryption reverses the shift to recover the original message.
